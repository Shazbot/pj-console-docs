pj_console

A campaign console for Total War: Warhammer III. Open it with the Console Commands button in the campaign menu bar, type a command and press Enter.

Try a command

>

    Tab or Enter accepts a suggestion, ↑ ↓ moves through them. Separate several commands with ;. Keys come from the base game, so modded units and bundles won't be listed, but the console still accepts them.

    Commands

    Most commands act on whatever you have selected on the campaign map: a character, a settlement or a faction. Click a row for arguments and examples.

    Keys

    Database keys from the base game, the values commands like au, eb or skill expect. Click a key to copy it.

      Console features

      Handled by the console box itself, before anything reaches the game.

      Several commands on one line

      Separate commands with a semicolon. They run in order.

      gg 100000; rp 5000; fff

      A line that starts with lua is never split, so Lua code can use semicolons freely.

      Aliases

      Give a name to a command or a whole chain. Aliases can call other aliases, up to five levels deep.

      alias rich = gg 500000; rp 20000
rich
aliases
unalias rich

      Aliases are saved to pj_console_aliases.txt next to the game executable, so they carry over between campaigns.

      Command files

      run <file> runs every line of a text file as if you typed it. The path is relative to the Warhammer III folder. Blank lines and lines starting with # or -- are skipped, and a file can run other files.

      # my_start.txt
fff
gg 200000
techall
      run my_start.txt

      History and output

      ↑ and ↓ in the console box step through your last 50 commands, which are kept in pj_console_history.txt. clear or cls empties the output panel.

      Context menus

      The Global, Character, Settlement and Faction buttons next to the console box list the common commands for the current selection. Entries without arguments run on click. The others put the command in the box and, where it takes a key, show suggestions.

      pj_console is a campaign mod for Total War: Warhammer III. Commands marked SP only refuse to run in multiplayer.
