Commands Keys Console features Changelog

13 Nov 2026, 3:11 pm

A rebuilt console box, command buttons for whatever you have selected, and a batch of new commands.

Console

  • Press Enter to run a command.
  • Use Up/Down to bring back your last 50 commands, even after restarting the game.
  • Run several commands at once by separating them with ;.
  • Create your own shortcuts:
    • alias name = command1; command2 creates one.
    • unalias name deletes one.
    • aliases lists them all.
  • clear / cls clears the console messages.
  • run <file> runs every command in a text file from your Warhammer 3 folder. Lines starting with # or -- are ignored.
  • You can drag the console anywhere on screen, and it remembers its position.
  • A message area under the console shows what you ran, errors, and a notice when a command isn't recognised.

Command buttons

  • New Global, Character, Settlement and Faction buttons under the console. Each one opens a list of commands for what you have selected.
    • Commands that need nothing else run straight away.
    • The rest are filled into the console for you to finish.
  • Hover a button to see which character, settlement or faction it will affect.
  • For commands that need a unit, trait, building, faction and so on, a searchable list opens.
    • Type to filter the list and use Previous/Next to page through it.
    • Names are shown alongside keys.
    • Items added by other mods are included.
    • Commands that need more than one key show a list for each in turn, e.g. merc lists units and then recruitment sources, spawn lists characters and then factions, and agent lists agent types and then subtypes. Close the list to skip an optional one.
    • Foreign slots (under) and Minor cult (unloc) also have a list.
  • New Diplomacy with faction button in the Global menu: pick an action, such as war, alliance or confederation, then any faction.
  • New Kill faction button in the Global menu, to pick any faction to destroy (killf).
  • New Character to pool button in the Global menu, to add any character to your recruitment pool (to_pool).
  • Spawn army is now also in the Character menu, to spawn an army next to the selected character.

Commands

  • confederate / confederate2 now work between factions that normally can't confederate, and tell you whether it worked.
  • au / add unit can now set the unit's rank.
  • Diplomacy commands (confederate, war, alliance, nap, breaktrade and others) can now target a faction by key.
  • New character, settlement, event, ritual and diplomacy commands, including forcing an alliance or trade agreement to break.
  • New single-player cheats:
    allskills
    Max out all skills of the selected character.
    armory
    Unlock every armory item the selected character can use.
    rankup [n]
    Give the selected character extra ranks.
    allancies
    Give your faction every ancillary.
    reset ritual <ritual>
    Reset a ritual's cooldown.
    dev unlock ritual <ritual>
    Unlock a ritual.
    take
    Take the selected settlement.
    hordegrowth <points> / hordedev
    Grow the selected horde.
    devpoints
    Add a development point to the selected settlement's province.
    cres <resource> <amount>
    Add any faction resource.

Fixes

  • Some commands, such as au and at with extra numbers, no longer run twice.
  • eb / reb no longer affect the previously selected character.
  • diplob2 works again.
  • Several faction and settlement commands no longer fail when no settlement is selected.
  • res now adds the correct amount.

Command reference

pj_console is a campaign mod for Total War: Warhammer III.
